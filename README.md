# Mechmate

Mechmate is an offline-first Flutter app for iOS, Android, and web. It is a workshop companion: pick a vehicle, describe what you hear, see, or feel, and get ranked causes with tests and repairs.

Copy never says "take it to a mechanic." Safety steps stay in the procedure, then the app tells you how to finish the job.

The public origin repo is https://github.com/Raeion/mechmate-app. The older private Raeion/MechMate C# project already used that name on GitHub, so this Flutter rebuild lives here.
